## Objetivo

Este projeto usará Supabase para:

- autenticação de usuários
- perfil MASTER e FUNCIONARIO
- banco de comprovantes
- lotes de impressão
- armazenamento de imagens e PDFs

## Próximas tabelas

- profiles
- comprovantes
- lotes
- logs

## Segurança

Usar Row Level Security (RLS).

Nunca usar service_role key no aplicativo.
