# Perlog Comprovantes - Status MVP

## Objetivo
Aplicativo para escanear comprovantes pequenos e organizar automaticamente em folhas A4 para impressão.

## Fluxo final planejado

1. Capturar comprovante pela câmera
2. Corrigir perspectiva e melhorar imagem
3. Ajustar tamanho aproximado de 6cm x 6cm
4. Salvar no lote diário
5. Organizar até 12 comprovantes por folha A4
6. Gerar PDF pronto para impressão
7. Compartilhar ou imprimir

## Configuração padrão

- Papel: A4
- Comprovante: 6cm x 6cm
- Layout: 3 colunas x 4 linhas
- Máximo: 12 comprovantes por página
